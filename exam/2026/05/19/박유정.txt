1.1 오픈 API 활용 가이드 확보
API 서비스명: 정보나루 인기대출도서 조회
기본 URL: http://data4library.kr/api/loanItemSrch
메서드: GET
인증: 발급받은 인증키(authKey)를 URL 파라미터로 전달

1.2 오픈 API 활용 가이드 이해
요청(Request): authKey(필수), startDt(조회 시작일), endDt(조회 종료일), format(응답 형식: json/xml)
응답(Response): 성공 시 200 OK와 함께 도서 목록(docs), 검색 결과 수(numFound) 등을 반환

1.3 API 통신 방법 분석
프로토콜: HTTP
데이터 형식: JSON (파라미터 format=json 사용 시)
인증 방식: Query Parameter 방식 (URL 뒤에 ?authKey=... 붙임)

1.4 필수 항목 작성
Base URL: http://data4library.kr/api/loanItemSrch
필수 파라미터: authKey
의존성: spring-boot-starter-web (RestTemplate 사용 목적)

1.5 요청 전달 및 결과 도출
@Service
public class LibraryService {

    public BookResponse getPopularBooks() {
        RestTemplate restTemplate = new RestTemplate();
        String url = "http://data4library.kr/api/loanItemSrch";
        
        // 1. URL과 파라미터 설정
        URI uri = UriComponentsBuilder.fromHttpUrl(url)
                .queryParam("authKey", "API_KEY") // 발급받은 키 넣기
                .queryParam("startDt", "2024-01-01")
                .queryParam("endDt", "2024-01-31")
                .queryParam("format", "json")
                .build()
                .toUri();

        // 2. API 호출 및 결과 받기
        BookResponse response = restTemplate.getForObject(uri, BookResponse.class);
        
        return response;
    }
}

    return response;

3.3 공통 모듈 구현
public class ApiUtil {
    // 상수 관리
    static final String KEY = "API_KEY";
    static final String BASE_URL = "http://data4library.kr/api/loanItemSrch";

    // 공통 호출 메서드
    public static BookResponse fetch(RestTemplate rt, String params) {
        String url = BASE_URL + "?authKey=" + KEY + "&format=json" + params;
        return rt.getForObject(url, BookResponse.class);
    }
}

}
