## BUG-001 필수 입력값 누락 검증 처리

회원가입 API 호출 시 `memberEmail`, `memberPwd`, `memberName` 중 하나가 누락되면 요청 데이터가 유효하지 않은 상태이다.

이 경우 서버 내부 오류로 처리하는 것이 아니라, 클라이언트 요청 오류인 `400 Bad Request`로 응답해야 한다.

수정 방향은 다음과 같다.

1. 회원가입 요청 DTO의 필수 필드에 검증 어노테이션을 추가한다.
2. `memberEmail`에는 `@NotBlank`, `@Email`을 적용한다.
3. `memberPwd`, `memberName`에는 `@NotBlank`를 적용한다.
4. Controller의 `@RequestBody` 앞에 `@Valid`를 추가한다.
5. 전역 예외 처리에서 `MethodArgumentNotValidException`을 처리한다.
6. 필수값 누락 시 `400 Bad Request`와 구체적인 안내 메시지를 반환한다.

| 요청 조건 | 수정 전 예상 문제 | 수정 후 기대 결과 |
| --- | --- | --- |
| `memberName` 누락 | 서버 오류 또는 부정확한 응답 발생 가능 | 400 Bad Request |
| `memberPwd` 누락 | 비밀번호 검증 없이 로직 진행 가능 | 400 Bad Request |
| `memberEmail` 형식 오류 | 잘못된 이메일 형식 저장 가능 | 400 Bad Request |
